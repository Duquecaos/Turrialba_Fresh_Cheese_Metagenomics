# Resistome analysis

This module integrates antimicrobial-resistance evidence at two
complementary levels:

1. the 18 final representative MAGs;
2. the six producer-level coassemblies.

It subsequently quantifies community ARG loci across the 18 shotgun
samples using the existing read-to-coassembly mappings.

## Upstream dependencies

The final-MAG analysis requires:

- the 18 representative MAGs;
- ABRicate results generated in `09b_abricate_screening`.

The community resistome requires:

- the six coassemblies generated by the assembly workflow.

ARG abundance quantification reuses the sample-to-coassembly BAM files
generated by the mapping workflow.

## Execution order

1. `91d_integrate_final18_resistome.slurm`
2. `91e1_amrfinder_coassemblies.slurm`
3. `91e2_consolidate_community_resistome.slurm`
4. `91f1b_quantify_ARG_loci_strict.slurm`
5. `91f1b_repair_consolidate.slurm`
6. `91f2_resistome_final_synthesis.slurm`

## Final-MAG resistome

Step 91d combines AMRFinderPlus and ABRicate evidence.

AMRFinderPlus is run using protein/nucleotide coordinate-aware evidence,
while ABRicate loci originate from the previously consolidated screening
with the CARD, MEGARes, NCBI and ResFinder databases.

Overlapping AMRFinderPlus and ABRicate calls are integrated at the
physical-locus level.

## Community resistome

Step 91e1 applies AMRFinderPlus to each of the six coassemblies.

Step 91e2 consolidates those loci and compares them with the resistome
represented by the 18 final MAGs, distinguishing:

- exact sequence representation in final MAGs;
- the same AMR symbol without exact sequence identity;
- additional community AMR symbols not represented by the final MAG set.

## ARG abundance

The canonical abundance analysis is the strict 91f1b workflow.

The earlier `91f1_quantify_ARG_loci.slurm` analysis was superseded and is
not part of the canonical workflow.

The original 91f1b script correctly generated strict per-sample coverage
files but contained legacy paths in its internal consolidation blocks.
`91f1b_repair_consolidate.slurm` reconstructed the final consolidated
tables from the strict 81b outputs.

For a cleaned public release, this repair should be incorporated directly
into the canonical strict-quantification script.

## Final synthesis

`91f2_resistome_final_synthesis.slurm` explicitly uses
`81b_resistome_ARG_abundance_strict` as the canonical coverage source and
integrates sample-, locus-, symbol-, producer-, week-, community- and
MAG-level evidence.
